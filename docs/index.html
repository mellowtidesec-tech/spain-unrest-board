目前情勢摘要

馬德里與巴塞隆納市區街頭治安持續全面回穩。馬德里出動400名警力於3日凌晨平和清空太陽門廣場（Puerta del Sol）334名紮營示威者，巴塞隆納警方與法院亦徹底瓦解Blocus掠奪組織，核心主謀全數收押。然而，台灣旅客即將抵達的11/5至11/15期間，將迎面碰上極度集中的鐵路大罷工潮：11/6與11/9 Ouigo廉價高鐵罷工、11/10與11/12西班牙國鐵Renfe司機罷工，以及11/11全西跨行業之全國大罷工（11-N）。高鐵城際移動、市區近郊通勤鐵路（Cercanías/Rodalies）與地鐵公車都將遭遇嚴重衝擊，須儘速重整交通行程。

旅遊實際影響與建議

  • 高鐵行程避坑：11/6、11/9（Ouigo司機罷工）及11/10、11/12（國鐵Renfe司機罷工）雙城往返高鐵將大砍班次，已購票者請儘速確認班次狀態；11/11當日跨城鐵路幾乎停擺，切勿安排城際移動。
  • 11/11全國大罷工當日應變：全西公共運輸（地鐵、公車、通勤火車）僅維持極低法定班次，部分超市、景點與餐廳可能自主關門歇業，建議將該日安排為飯店周邊步行觀光，並提前於前一日備足糧水。
  • 機場聯絡交通：受國鐵司機罷工影響，馬德里Cercanías C-1/C-10機場線及巴塞隆納Rodalies R2 Nord將大幅減班，往返機場建議優先選擇地鐵機場線、機場接駁巴士（Aerobús / Exprés Aeropuerto）或預約計程車/Cabify，並預留至少4小時抵達機場。
  • 市區景點通行：馬德里太陽門廣場（Sol）已完全清場通行，景點秩序恢復；巴塞隆納市中心商圈已恢復正常，但行經主要政府機構、工會大樓（如巴塞隆納大學廣場、馬德里交通部週邊）時若遇集會人潮請儘速繞行。
