目前情勢摘要

馬德里與巴塞隆納街頭治安在警力強勢掃蕩與司法收押首腦後恢復平穩，商圈防護木板多已拆除。然而，即將抵達西班牙（11/5-11/15）的旅客面臨嚴峻的交通考驗：11/6與11/9 Ouigo高鐵罷工、11/10與11/12西班牙國鐵Renfe司機罷工，以及11/11全國跨行業大罷工（11-N）。鐵路、地鐵、市區公車甚至計程車均將面臨大減班或停駛，雙城間長途高鐵與通勤鐵路調度高度混亂，務必提前排定替代行程。

  • 城際高鐵避險：11/6與11/9持有Ouigo車票者請密切注意停駛公告，盡早備妥Iryo或Renfe替代票；11/10至11/12為Renfe與全國大罷工高峰，馬德里與巴塞隆納間移動強烈建議避開此三日，或改訂內陸航班。
